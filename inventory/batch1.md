## Flags

- **Filename is misleading — not exam material:** `TOPIK-I-1671.pdf` looks like it could be an actual TOPIK I test paper by name, but it is only a plain numbered English-gloss vocabulary list. Do not treat as mock-exam content without re-verifying.
- **High-priority Reading/mock-exam finds (both confirmed by direct visual inspection, not inference):**
  1. `521064083-korea-book-yonsei-topik-2-읽기.pdf` — Yonsei University's official TOPIK II Reading prep book, full passages + real question-number ranges + answer explanations, organized by question type across the whole 50-question reading structure. This is a top candidate for extraction.
  2. `735876229-Hot-Topik-New-đỏ-sach-Giải.pdf` — "HOT TOPIK II Actual Test" 해설집 (explanation book), 5 full mock-exam rounds, confirmed real passages (including literary excerpts) + questions + choices + explanations for both Listening and Reading. Note it's the *answer/explanation* edition, not a blank question booklet — good for extraction but not for building a timed "blind" practice mode as-is.
  3. `588613293-Cracking-the-TOPIK-2-Writing.pdf` — genuine TOPIK II Writing exam-format material (not Reading, but fills the adjacent Writing gap) — 5 mock tests, real Q51–54 style exercises.
- **No pdftoppm/poppler installed in this environment** — all visual inspection for this batch was done via PyMuPDF (installed mid-task via pip) rendering pages to PNG directly, since the Read tool's built-in PDF viewer depends on pdftoppm which is absent. Flagging in case future batches hit the same tool gap.
- **Unicode filename quirks:** `735876229-Hot-Topik-New-đỏ-sach-Giải.pdf` and `KCC - Group call vocabulary - 2025.8월.pdf` could not be opened by literal-string path matching in Python (NFC/NFD Unicode normalization mismatch between how the filename was typed vs. how Windows stores it) — had to resolve via `os.listdir()` directory match instead. Worth remembering for later extraction passes on these two files.
- **Series/volume note (not true duplicates):** `vitamin_1.pdf` and `vitamin_6.pdf` are volumes 1 and 6 of the same 6-book "비타민 한국어 (Vitamin Korean)" Darakwon series. Volumes 2–5 (`vitamin_2.pdf` through `vitamin_5.pdf`) also exist in the Downloads folder but were not included in this 22-file batch — flagging so a later batch/pass picks them up rather than assuming this batch is the complete series.
- **No corrupted/unopenable files** — all 22 files opened successfully with pypdf and yielded a plausible page count; none are empty or zero-byte.
- **No exact duplicate filenames within this batch of 22** — no wrong-exam-entirely content either (everything is genuinely Korean-language / TOPIK-adjacent).
